# AI-Gemini-integration
Функция для вызова бесплатного ии от Gemini
На место API REY... вставить свой ключ, который получается бесплатно на:
https://aistudio.google.com/api-keys?project=gen-lang-client-0116266092
(При наличии других аккаунтов можете получить другие ключи и просто добавить их в список API)

При вызове функции просто пришлите сообщение которое хотите отправить ИИ и он вернет вам его ответ
При возникновении ошибок функция вернет Error
